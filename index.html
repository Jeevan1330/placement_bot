Module 3

Core Technical Interview Hub

Review high-yield questions asked in technical rounds at top product and service IT companies.

DSA What is the difference between an Array and a Linked List in memory and access time? +

Memory Layout: Arrays store elements in contiguous (adjacent) memory blocks. Linked lists allocate memory dynamically for individual nodes scattered throughout the heap, linked together using pointers.

Time Complexities:

  • Access by Index: Array is O(1) constant time; Linked List is O(N) linear time.
  • Insertion at Beginning: Array is O(N) due to shifting elements; Linked List is O(1) by updating head pointer.
  • Memory Overhead: Arrays have zero pointer overhead; Linked lists require extra memory per node for storing pointers (4 or 8 bytes).
DSA Explain the two-pointer approach and where it is most effectively applied. +

The two-pointer technique uses two pointers that traverse a data structure (typically a sorted array or linked list) simultaneously, either in the same direction or from opposite ends.

Common Applications:

  • Pair Sum in Sorted Array: Left pointer starts at 0, right pointer starts at N-1. If sum is smaller than target, increment left; if larger, decrement right. Reduces O(N²) brute-force to O(N).
  • Detecting Cycles: Floyd's Tortoise and Hare algorithm uses a slow pointer (1 step) and fast pointer (2 steps) to detect cycles in O(N) time and O(1) space.
DBMS What are ACID properties in a Relational Database? Give a real-world banking example. +

ACID guarantees that database transactions are processed reliably:

  • Atomicity: "All or nothing". If money is debited from Account A, it must be credited to Account B. If the server crashes midway, the debit is rolled back completely.
  • Consistency: The database must transition from one valid state to another, satisfying all constraints (e.g. Account balance cannot drop below zero).
  • Isolation: Concurrent transactions run independently without interfering with each other (e.g. Two people withdrawing from the same joint account at the same second).
  • Durability: Once a transaction commits, the record is permanently written to non-volatile storage and survives power failures.
OS What is a Deadlock and what are the four Coffman conditions necessary for a deadlock to occur? +

A deadlock is a situation where two or more processes are permanently blocked because each process holds a resource and waits for another resource held by another process.

The 4 Coffman Conditions:

  1. Mutual Exclusion: At least one resource must be held in a non-shareable mode.
  2. Hold and Wait: A process holds at least one resource while requesting additional resources.
  3. No Preemption: Resources cannot be forcibly confiscated from a process; they must be released voluntarily.
  4. Circular Wait: A closed chain of processes exists such that each process holds one resource needed by the next process in the chain.

⭐

The STAR Response Framework

Use this 4-step structure to answer behavioral questions like "Describe a challenge you faced" or "Tell me about a team conflict".

S
Situation: Set the context. Briefly state the background, company or college project, and team size.
T
Task: Explain your specific responsibility or problem that needed to be resolved.
A
Action: Detail the concrete steps you personally took. Mention tools, leadership, or code solutions.
R
Result: Share the quantifiable outcome (e.g., "reduced latency by 30%", "received top grade", "delivered 2 days early").
💼

Top HR Questions & Winning Strategies

1. "Tell me about yourself."

Formula (Present-Past-Future): Who you are (degree, specialization), key technical accomplishments or projects, and why this specific company aligns with your career goals. Keep it strictly under 90 seconds.

2. "What is your greatest weakness?"

Winning Strategy: Pick a real professional area that isn't fatal to the job, and show the active steps you are taking to overcome it (e.g., "I used to hesitate speaking in large groups, so I joined our college debate club and took public speaking seminars").

3. "Do you have any questions for us?"

Winning Strategy: Never say "No". Ask: "What does a typical onboarding trajectory look like for a graduate engineer on your team?" or "What technologies is the team planning to adopt over the next year?"
